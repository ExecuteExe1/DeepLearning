
## Image Classification Using Machine Learning

This project implements and compares multiple machine learning algorithms for image classification, including custom 1-Nearest Neighbor (1-NN), 3-Nearest Neighbor (3-NN), Nearest Centroid, and a Multi-Layer Perceptron (MLP) neural network.

Images are preprocessed through grayscale conversion, resizing to 32×32 pixels, and flattening into feature vectors. Principal Component Analysis (PCA) reduces feature dimensionality from 1,024 to 50 components.

The classifiers are evaluated using training and testing accuracy, execution time, and visualizations of correctly and incorrectly classified images.

**Technologies:** Python, NumPy, Pandas, Scikit-learn, Matplotlib, Pillow, Scikit-image.
